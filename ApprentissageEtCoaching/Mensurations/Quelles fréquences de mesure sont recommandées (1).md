# Quelles fréquences de mesure sont recommandées

Pour un régime, les experts recommandent de mesurer les mensurations corporelles toutes les 2 à 4 semaines pour observer des changements réels sans fluctuations quotidiennes dues à l'eau ou aux repas. Le poids peut être suivi plus souvent (2-7 fois par semaine, moyenne hebdo) car il motive et aide à ajuster vite, mais évite le quotidien si ça stresse. Adapte à ton objectif : plus fréquent en phase active, mensuel en maintien.[^1][^2][^3][^4][^5][^6]

## Fréquences par indicateur

| Indicateur | Fréquence recommandée | Pourquoi ? |
| :-- | :-- | :-- |
| Mensurations (taille, hanches...) | Toutes les 2-4 semaines [^1][^2][^3] | Temps pour perte de gras visible ; trop souvent = bruit (rétention d'eau). |
| Poids sur balance | 2-7x/semaine (matin, moyenne hebdo) [^4][^5][^6] | Suit tendance calorique ; études montrent + d'efficacité pour perte poids. |
| Photos avant/après | 1x/mois [^7][^8] | Visuel motivant ; voit définition musculaire. |
| IMC / % graisse (si impédancemètre) | 1x/mois [^2][^9] | Précis pour recomposition ; pas quotidien (variabilité hydratation). |

## Conseils d'application

Toujours mesurer dans les mêmes conditions (matin à jeun, posture relaxée) pour comparer valablement. Si débutant, commence par 1x/2 semaines pour les tours + pesée 3x/semaine ; ajuste si obsession. Combine avec app (Yazio/Foodvisor) pour alertes auto et graphiques tendances. Si stagnation >4 semaines, revois calories/sport plutôt que mesures plus fréquentes.[^2][^3][^4][^6][^10][^11][^1]
