Utilité de l'autoevaluation.
Elle se base sur la methode CAMA
Comprendre, Appliquer, Monitorer, Adapter
On l'utilise pour creer des habitudes et mesurer les progres
Mais c'est utile pour voir a quel point on est autonome sur le programme.
Le but est d'avoir un mode de vie sain pour maintenir les resultats a long terme
Donc à partir du 18/12/2025, il faut s'autoevaluer tous les jours
1) Repondre a quelques questions sur ressenti et progres
2) Noter progres sur Excel ou carnet
Comment se passe ma journée (1a5)
quel est mon niveau de motivation (1-5)
Comment avez vous dormi (1a5)
Niveau de stress (1a5)
Acitivité physique oui / non / planifiée
Faire un defi du jour oui / non / planifiée
Avez vous utilisé un plan d'action contre une tentation
